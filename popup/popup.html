Terms & Privacy

Data Processing: When you upload a resume or view a LinkedIn job, the text is sent to Google's Gemini AI API using your own API key. By using this extension, you acknowledge and consent to this.

What is sent to Gemini: Resume text (PDF/DOCX content) and job description text scraped from LinkedIn.

What is stored locally: Only the extracted keyword list from your resume (not the full text). Your Gemini API key. Your consent record.

No external servers: The extension developer (Jayadev) operates no backend servers. No data is sent anywhere except directly to Google's Gemini API.

Liability disclaimer: This extension is provided "as is". The developer (Jayadev) accepts no liability for decisions made based on ATS scores, for data processed through the Gemini API, or for any outcomes related to job applications.

GDPR: You may delete all stored data at any time via Settings → Delete All My Data.
